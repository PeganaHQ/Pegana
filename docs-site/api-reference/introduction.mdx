The endpoints listed in this tab are generated from the live OpenAPI spec at
[api.pegana.xyz/openapi.json](https://api.pegana.xyz/openapi.json).
Use the **try-it-now** panel on each endpoint to send a real request.

<Note>
  The OpenAPI spec is assembled from utoipa annotations on the axum handlers and
  covers the full `/v1` surface (24 paths, enforced in CI). It's the source of
  truth the first-party TypeScript and Python SDKs are generated from.
</Note>

## Base URL

```
https://api.pegana.xyz
```

## Authentication

Every endpoint is **public** — no `Authorization` header, no API key. See
[authentication](/authentication).

## Rate limit

Per-IP sliding window: currently **60 req/min** on REST (see the `RateLimit-Limit` header). WebSocket allows **20 concurrent
connections per IP**. Liveness / readiness probes are exempt.

Need more? Email `rafael@pegana.xyz`.

## Cross-origin

CORS allowed from `pegana.xyz`, `www.pegana.xyz`, `localhost:3000` by default.
Self-hosted instances can extend via `CORS_EXTRA_ORIGINS`.

## Errors

Standard HTTP codes. Error bodies carry a stable `error` code, usually as
`{"error": "...", "message": "..."}`. Every code is listed in [Errors](/guides/errors).

## SDKs

First-party typed clients — **TypeScript** (`@peganahq/sdk-ts`) and **Python**
(`pegana-sdk`) — are generated from the OpenAPI spec above and cover every `/v1`
endpoint, plus a hand-written live-feed WebSocket helper (`PegFeed` / `peg_feed`).

```sh
npm install @peganahq/sdk-ts
pip install pegana-sdk
```

<Warning>
The releases on npm (`@peganahq/sdk-ts` 0.3.1) and PyPI (`pegana-sdk` 0.3.0) predate the
2026-10-20 endpoint removals: they still include `/v1/alerts`, `/v1/auth/*` and `/v1/me/*`
calls, which return `404`. Version 0.4.0 of both drops them and is not published yet. Once
the public [PeganaHQ/Pegana](https://github.com/PeganaHQ/Pegana) repository carries 0.4.0
(check the `version` in `sdk/typescript/package.json` and `sdk/python/pyproject.toml`), you can
build it from a clone: run `npm install && npm pack` in `sdk/typescript` (it builds `dist/`)
and install the resulting tarball, or run `pip install ./sdk/python` (Python 3.11 or later).
</Warning>

Reads need no API key.

Prefer your own client? Generating one from
[openapi.json](https://api.pegana.xyz/openapi.json) is a first-class path — it's
exactly how the first-party SDKs are built (`openapi-typescript` + `openapi-fetch`
for TypeScript, `openapi-python-client` for Python; orval also works).
