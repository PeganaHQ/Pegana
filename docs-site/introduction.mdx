## What Pegana does

Pegana watches **66 pegged assets on Solana mainnet** in real time (live count on
2026-10-20; see `GET /v1/assets`). For every asset, we compare market price to intrinsic value, smooth
the spread with an EWMA, and publish a peg state through a 5-state FSM:
**PEGGED · DRIFT · DEPEG · CRITICAL · BLACK_SWAN**. (UNKNOWN is a separate non-alerting
status — cold-start or a detectably broken anchor — not a severity band.)

When the state changes, we emit an alert. That's the whole product.

```
spread = 1 − market / intrinsic
```

Everything else is plumbing.

## Coverage

**66 assets on the public peg surface across 6 classes** (live count) — **mainnet only**, no devnet feeds. Source of
truth: [`assets.toml`](https://github.com/PeganaHQ/Pegana/blob/main/assets.toml);
the canonical **live** list, with each asset's current peg state, is always
[`GET /v1/assets`](/guides/rest-api). Some assets carry a `monitoring_only` flag
(alerts live but labeled beta while the calibration is provisional); the live
calibration status of each asset is always on `GET /v1/assets` — treat any
`monitoring_only` read as experimental until it graduates.

| Class        | Active | Examples                                               |
| ------------ | ------ | ------------------------------------------------------ |
| lst          | 43     | jitoSOL, mSOL, bSOL, INF, JupSOL, BNSOL, STKESOL …     |
| stable_yield | 10     | USDY, sUSDe, syrupUSDC, JLP, ONyc, PST, eUSX, USD\* …  |
| stable_fiat  | 7      | USDC, USDT, PYUSD, USDG, USD1, USDu, CASH              |
| stable_dn    | 3      | USDe, JupUSD, USX                                      |
| stable_cdp   | 2      | USDS, hyUSD                                            |
| stable_fx    | 1      | EURC                                                   |

The asset set grows over time — treat this table as a snapshot and `GET /v1/assets`
as the source of truth for what is live right now.

**Inactive entries** (in `assets.toml` with `active = false`, not polled, so not in
the public set): `BRZ` (BRL FX-pegged) and `pbUSDC` — deactivated 2026-06-01 (only thin dust
DEX pairs left, prices unreliable), and `AUSD`, retired 2026-10-22 (no Solana market and no
sponsored Pyth feed on Solana). `dSOL` was removed after the Drift exploit
(2026-04-01) and survives only as a historical comment.

## What we promise

- **Methodology is public.** Every threshold, every source, every smoothing parameter
  lives in [/methodology](/methodology/overview). No black box.
- **Verifiable, with published source.** The methodology, verifier, replay CLI and SDKs
  are open source under MIT. The indexers, engine, API, dispatcher, MCP server and other
  service code are source-available under FSL-1.1-MIT at
  [`github.com/PeganaHQ/Pegana`](https://github.com/PeganaHQ/Pegana). The `web/` app is
  proprietary. See the [license map](https://github.com/PeganaHQ/Pegana/blob/main/LICENSING.md). The
  `pegana-replay` CLI that reproduces receipts is also mirrored at
  [`github.com/PeganaHQ/ReplayCLI`](https://github.com/PeganaHQ/ReplayCLI) —
  re-derive a verdict yourself (use the release matching the receipt's methodology version; 0.4.0 onward).
- **No API key, ever.** REST, WebSocket, MCP and Embed are public and free.
- **One source per asset class.** We do not "blend" prices. Sanctum exchange rates —
  or a direct on-chain stake-pool read for LSTs outside the Sanctum registry — for LST
  intrinsic; Pyth for FX and for yield-bearing redemption rates; on-chain vault/CDP
  decode for Hylo, Solayer, and Perena USD\*; Jupiter for routed market price.
